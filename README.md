# ポートフォリオ（パーティクル・ネットワーク）

## 概要
- マウスに反応するパーティクルがネットワークを形成する、視覚的に印象的なポートフォリオ。
- フレームワーク不使用（純粋な HTML/CSS/JavaScript）。
- `index.html` をブラウザで開くだけで閲覧可能。

## 主要機能
- **綺麗なパーティクルシステム**: Canvas 上で浮遊し、近接すると線で結合。
- **マウス追従機能**: ポインタに引かれる自然な挙動。
- **グラデーション背景**: 固定背景で没入感。
- **レスポンシブデザイン**: グリッド・タイポグラフィを可変に。
- **スムーズなアニメーション**: requestAnimationFrame、距離計算最適化。
- **モダンデザイン**: ガラス感のあるカード、適度なシャープネス。

## Core Web Vitals 対応
- **LCP**: 初回ビューを軽量化（ヒーロー内のテキストを優先、画像不使用）。
- **CLS**: 固定レイアウトとシンプルなフォント指定でレイアウトシフトを抑制。
- **INP**: pointermove は軽量処理（二乗距離比較、近接判定の簡略化）。
- **パフォーマンス**: デバイスピクセル比を上限 1.75 に制限、モバイル時のパーティクル数を削減。

## 使い方
1. このフォルダの `index.html` をダブルクリックで開く（またはローカルサーバでも可）。
2. マウスを動かすとパーティクルが反応し、近接時に線で結合。

## カスタマイズ
- `script.js` の `baseCount` を変更してパーティクル数を調整。
- `linkDist` を変更して線の結合距離を調整。
- `styles.css` の `--accent` や背景グラデーションを好みに合わせて変更。

## 注意点
- ファイル内コメントは全て日本語。
- 高 DPI 環境で負荷が高い場合は `dpr` の上限を下げる。
